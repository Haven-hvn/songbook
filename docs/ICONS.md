# Icons

`core-design/.../AppIcons.kt` is generated from Material Symbols (Rounded, filled, 24px):

`https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/<symbol>/materialsymbolsrounded/<symbol>_fill1_24px.svg`

The outlined variants (`FavouriteOutline`, `PinOutline`) come from `<symbol>_24px.svg`. Each file holds one `<path>`; its `d` attribute is the string in `AppIcons.kt`. Most symbols use a 960 unit grid (`viewBox="0 -960 960 960"`); `push_pin` is still on the 24 unit grid and is marked `grid = 24f`.

Material Symbols are licensed under Apache-2.0 (see `NOTICE`).
